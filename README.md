# MAETRADE

Personal Trading Operating System — GitHub Pages V1.

## Features
- Dashboard / command center
- Technical Analysis workspace
- Trading Journal
- New Trade modal
- Trade filters and performance metrics
- Cashflow workspace
- Settings
- Responsive mobile navigation
- Browser `localStorage` persistence

## Design
- Primary: `#2C666E`
- Light text: `#F0EDEE`
- Compact Bento / premium trading workspace
- GitHub Pages compatible
- No build step required

## GitHub Pages
Upload these files to the root of the `main` branch and enable:

`Settings → Pages → Deploy from branch → main → /(root)`

## Data
This V1 uses browser `localStorage`. The future production architecture can connect the UI to Workers + D1.
