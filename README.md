# MAETRADE

Personal Trading Operating System — GitHub Pages V1.

## Files
- `index.html` — application shell and UI
- `style.css` — responsive visual system
- `script.js` — navigation, New Trade, journal, localStorage analytics
- `.nojekyll` — GitHub Pages static-site hardening

## Storage
Trade records are stored locally in the browser under `maetrade_v1_trades`. This V1 does not sync to Cloudflare D1.

## GitHub Pages
Upload all files to the repository root and publish the `main` branch from `/(root)`.
